# Brainstorm de Design - Portfólio Diego Santos

## Conceito Geral
Portfólio profissional para Engenheiro de Dados com foco em pipelines, automação e IA. O design deve comunicar:
- Profissionalismo e expertise técnica
- Inovação e pensamento moderno
- Capacidade de resolver problemas complexos
- Experiência em negócios + tecnologia

---

## Resposta 1: "Minimalismo Técnico com Acentos Dinâmicos"
**Probabilidade:** 0.08

### Design Movement
Minimalismo Suíço + Modernismo Digital — Inspirado em portfólios de engenheiros de topo (Stripe, Vercel, Linear). Foco em clareza, hierarquia e espaço negativo.

### Core Principles
1. **Clareza Radical:** Cada elemento tem propósito. Sem decoração desnecessária.
2. **Hierarquia Tipográfica:** Tipografia forte comunica estrutura e importância.
3. **Acentos Estratégicos:** Cores vibrantes (azul elétrico, verde neon) em momentos-chave para quebrar minimalismo.
4. **Movimento Sutil:** Transições suaves que não distraem, apenas guiam.

### Color Philosophy
- **Paleta Base:** Preto/Cinza muito escuro (fundo), Branco/Off-white (texto)
- **Acentos:** Azul elétrico (#0066FF) para CTAs e destaques, Verde neon (#00FF88) para sucesso/dados
- **Raciocínio:** Comunica tecnologia, precisão, modernidade. Cores vibrantes mostram inovação.

### Layout Paradigm
- **Hero:** Assimétrico — Texto à esquerda (grande, bold), visualização de dados/código à direita
- **Seções:** Alternância entre full-width e grid 2-col
- **Projetos:** Card grid com hover effect sutil (aumento de elevação, não cor)
- **Navegação:** Sticky header minimalista, apenas logo + links principais

### Signature Elements
1. **Linhas Geométricas:** Divisores horizontais/verticais que criam ritmo visual
2. **Números & Métricas:** Destaque de impacto (15 anos, 80% redução, 146 contribuições) em tipografia grande
3. **Código Snippets:** Pequenos blocos de código (Python, SQL) como elementos decorativos em seções

### Interaction Philosophy
- Hover states revelam informação (ex: cards expandem levemente)
- Scroll triggers animações suaves (fade-in, slide-up)
- Botões mudam cor ao hover (azul → verde neon)
- Links têm underline animado

### Animation
- **Entrance:** Fade-in + slide-up (200ms, ease-out) para elementos ao scroll
- **Hover:** Scale 1.02 + shadow increase para cards
- **Loading:** Animated gradient pulse (não spinner)
- **Transitions:** Todas 300ms cubic-bezier(0.4, 0, 0.2, 1)

### Typography System
- **Display:** IBM Plex Mono Bold (títulos grandes, 48-64px) — comunica técnico
- **Heading:** Inter SemiBold (32-40px) — legível, moderno
- **Body:** Inter Regular (16px) — leitura confortável
- **Accent:** IBM Plex Mono Regular (código, métricas) — 14px
- **Hierarquia:** Contraste de peso, não tamanho

## Resposta 2: "Orgânico Moderno com Gradientes Fluidos"
**Probabilidade:** 0.07

### Design Movement
Glassmorphism + Neumorphism — Inspirado em design de produtos (Apple, Figma). Suave, acessível, premium.

### Core Principles
1. **Suavidade:** Bordas arredondadas, sombras soft, sem ângulos agressivos.
2. **Profundidade:** Camadas visuais criam dimensão sem ser pesado.
3. **Movimento Orgânico:** Gradientes fluidos, animações que respiram.
4. **Acessibilidade:** Alto contraste, tipografia generosa.

### Color Philosophy
- **Paleta Base:** Fundo gradiente (azul escuro → roxo profundo), Texto branco
- **Acentos:** Gradiente ciano → magenta para CTAs, Ouro suave para destaque
- **Raciocínio:** Moderno, premium, criativo. Gradientes sugerem fluxo de dados.

### Layout Paradigm
- **Hero:** Centrado com gradiente de fundo animado, imagem abstrata à direita
- **Seções:** Cards com glassmorphism (semi-transparent, backdrop blur)
- **Projetos:** Carousel com cards que fluem
- **Navegação:** Floating nav bar (semi-transparent, glassmorphism)

### Signature Elements
1. **Gradientes Animados:** Fundo que muda lentamente ao scroll
2. **Ícones Customizados:** Ícones com gradientes (não monocromáticos)
3. **Blobs & Shapes:** Formas orgânicas (não geométricas) como decoração

### Interaction Philosophy
- Tudo responde ao movimento do mouse (parallax suave)
- Hover revela informação em cards (blur effect)
- Scroll ativa animações de entrada (stagger effect)
- Cliques têm ripple effect suave

### Animation
- **Entrance:** Blur-in + scale 0.95→1 (400ms, ease-out)
- **Hover:** Glow effect + slight lift (shadow increase)
- **Background:** Gradiente que anima lentamente (30s loop)
- **Transitions:** Todas 400ms cubic-bezier(0.34, 1.56, 0.64, 1)

### Typography System
- **Display:** Poppins Bold (48-72px) — amigável, moderno
- **Heading:** Poppins SemiBold (32-40px) — hierarquia clara
- **Body:** Poppins Regular (16px) — legível, espaçado
- **Accent:** IBM Plex Mono (dados, código) — 14px
- **Hierarquia:** Peso + cor (gradiente em títulos)

## Resposta 3: "Data Visualization Centric com Tema Corporativo"
**Probabilidade:** 0.06

### Design Movement
Data Storytelling + Corporate Modern — Inspirado em dashboards de dados (Tableau, Looker). Informação é o design.

### Core Principles
1. **Dados Primeiro:** Visualizações de dados são o destaque, não decoração.
2. **Corporativo Acessível:** Profissional mas não entediante.
3. **Narrativa Visual:** Cada seção conta uma história (experiência, skills, projetos).
4. **Interatividade:** Usuários exploram dados, não apenas leem.

### Color Philosophy
- **Paleta Base:** Cinza neutro (fundo), Azul corporativo (primário)
- **Acentos:** Verde (sucesso/crescimento), Laranja (atenção), Vermelho (impacto)
- **Raciocínio:** Cores de dados (semáforo). Comunica expertise em análise.

### Layout Paradigm
- **Hero:** Gráfico de timeline (experiência ao longo do tempo) como fundo
- **Seções:** Mix de texto + visualizações (charts, graphs)
- **Projetos:** Cards com mini-charts mostrando impacto
- **Navegação:** Sidebar com progress indicator (onde está na página)

### Signature Elements
1. **Gráficos Animados:** Charts que animam ao scroll (bars crescem, linhas desenham)
2. **Timeline Interativa:** Experiência profissional como timeline visual
3. **Skill Bars:** Habilidades com barras animadas (não apenas texto)

### Interaction Philosophy
- Hover em cards mostra dados detalhados (tooltip)
- Clique em projeto abre modal com visualização de impacto
- Scroll anima gráficos (draw effect)
- Filtros interativos (ex: filtrar projetos por tecnologia)

### Animation
- **Entrance:** Draw effect para gráficos (1s, ease-in-out)
- **Hover:** Highlight + tooltip fade-in
- **Transitions:** 500ms ease-in-out
- **Charts:** Bars crescem, linhas desenham, números contam

### Typography System
- **Display:** IBM Plex Sans Bold (48-64px) — corporativo, técnico
- **Heading:** IBM Plex Sans SemiBold (32-40px) — estrutura
- **Body:** IBM Plex Sans Regular (16px) — profissional
- **Data:** IBM Plex Mono (números, métricas) — 14-18px
- **Hierarquia:** Peso + cor (dados em destaque)

## Decisão Final

**Escolhido: Resposta 1 - "Minimalismo Técnico com Acentos Dinâmicos"**

### Por quê?
1. **Alinhamento com Público:** Recrutadores de tech valorizam clareza e modernidade
2. **Profissionalismo:** Comunica expertise sem parecer genérico
3. **Diferencial:** Acentos dinâmicos (azul + verde neon) quebram minimalismo e mostram criatividade
4. **Performance:** Minimalismo = carregamento rápido, sem distrações
5. **Replicabilidade:** Fácil de manter e atualizar

### Implementação
- **Tipografia:** IBM Plex Mono (títulos) + Inter (corpo)
- **Cores:** Preto (#0a0a0a), Azul (#0066FF), Verde (#00FF88), Branco (#ffffff)
- **Layout:** Assimétrico, cards com hover sutil, navegação sticky
- **Animações:** Fade-in, slide-up, scale suave, underline animado
- **Componentes:** Hero assimétrico, grid de projetos, timeline de experiência, skill bars
